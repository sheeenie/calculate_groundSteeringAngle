## Commit style
The commits shall start with # and then the issue number the commit is connected to. The commit shall be maximum 50 characters long and it shall be written in present tense. A commit shall follow the following structure: If I make this commit I will <the commit message>. No punctuation mark shall be used at the end of the commit message.

An example of a commit message:
#64 Add attributes to class Car
